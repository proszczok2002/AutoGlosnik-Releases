# Bezpieczeństwo wydań

Pobieraj APK wyłącznie z sekcji Releases tego repozytorium.

SHA-256 certyfikatu podpisującego wydania od wersji 1.0:

`60A685333B8B79BD70998D692FD44F73D236B043429505C7555DDF7BECBF3326`

Updater dodatkowo sprawdza sumę SHA-256 pliku, nazwę pakietu
`pl.bumbox.autospeaker`, rosnący `versionCode` i zgodność podpisu.

Podejrzenie podatności należy zgłosić przez
[prywatne zgłoszenie bezpieczeństwa](https://github.com/proszczok2002/AutoGlosnik-Releases/security/advisories/new),
zamiast publikować szczegóły umożliwiające nadużycie w zwykłym Issue.

Zwykłe błędy działania można zgłaszać przez przygotowany
[formularz problemu](https://github.com/proszczok2002/AutoGlosnik-Releases/issues/new?template=bug_report.yml).
