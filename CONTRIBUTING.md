# Zgłaszanie problemów i propozycji

Dziękujemy za pomoc w ulepszaniu AutoGłośnika.

## Zwykły błąd

1. Sprawdź [pełną instrukcję](INSTRUKCJA.md) i istniejące Issues.
2. Użyj przygotowanego
   [formularza zgłoszenia](https://github.com/proszczok2002/AutoGlosnik/issues/new/choose).
3. Podaj wersję AutoGłośnika, model telefonu, wersję Androida, używaną
   aplikację Telefon, dokładne kroki i oczekiwane działanie.
4. Nie publikuj numerów telefonu, danych rozmów, adresów, tokenów ani innych
   danych osobowych.

## Podatność bezpieczeństwa

Nie otwieraj publicznego Issue. Użyj
[prywatnego zgłoszenia bezpieczeństwa](https://github.com/proszczok2002/AutoGlosnik/security/advisories/new).

## Dokumentacja i kod

To repozytorium pozostaje kanałem zgodności aktualizatora. Kod źródłowy jest
publiczny w [głównym repozytorium](https://github.com/proszczok2002/AutoGlosnik),
które przyjmuje Issues i Pull Requesty. Pełne zasady współpracy opisuje
[CONTRIBUTING.md](https://github.com/proszczok2002/AutoGlosnik/blob/main/CONTRIBUTING.md)
w głównym projekcie.
