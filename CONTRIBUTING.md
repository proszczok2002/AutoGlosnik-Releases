# Zgłaszanie problemów i propozycji

Dziękujemy za pomoc w ulepszaniu AutoGłośnika.

## Zwykły błąd

1. Sprawdź [pełną instrukcję](INSTRUKCJA.md) i istniejące Issues.
2. Użyj przygotowanego
   [szablonu zgłoszenia](https://github.com/proszczok2002/AutoGlosnik-Releases/issues/new?template=bug_report.md).
3. Podaj wersję AutoGłośnika, model telefonu, wersję Androida, używaną
   aplikację Telefon, dokładne kroki i oczekiwane działanie.
4. Nie publikuj numerów telefonu, danych rozmów, adresów, tokenów ani innych
   danych osobowych.

## Podatność bezpieczeństwa

Nie otwieraj publicznego Issue. Użyj
[prywatnego zgłoszenia bezpieczeństwa](https://github.com/proszczok2002/AutoGlosnik-Releases/security/advisories/new).

## Dokumentacja i kod

To repozytorium służy do dystrybucji oficjalnych APK i dokumentacji. Kod
źródłowy pozostaje prywatny, dlatego repozytorium nie przyjmuje zmian kodu przez
Pull Request. Błąd albo propozycję poprawki dokumentacji można zgłosić w Issues.
